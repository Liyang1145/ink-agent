# InkAgent：语音、实时画板与共享笔记

InkAgent 的目标不只是让 AI 帮忙写笔记，而是让学习者能边说、边看、边动手。一次讲解可以被打断、被改动，最后只把学习者明确选择的内容留在笔记里。参考的是可随时插话的通话体验，不依赖 Dot 本体或其内部实现。

## 第一个可用演示

用两个测向扇形的交集来讲定位：先画两个观测点与可行区域，再让学习者说「停一下，把第二个观测点挪远」。立刻停住当前语音和动画；学习者也可以用手直接拖点。按新位置重算交集，对照面积与最大点间距。当学习者说「把现在这张留下」，才把当前选中的图写到指定笔记页，一次撤销即可移除。未选中的演示帧不自动写入。

## 分开管理三种状态

- **对话**：接收语音、识别插话，控制播报、取消和恢复。先在本地立即停声，不等待服务器确认。把每段输出与当前讲解代次关联；不能标记来源的音频流，取消后本地静音，直到明确进入新一代。
- **画板**：维护场景、参数、播放位置和选中对象。拖动更新由本机计算，合并高频事件；语音只需要知道最新参数。场景版本与播放代次分开：暂停不改变场景，也不推进时间；清空则废弃旧场景和旧结果。旧模型回复、定时器或截图回调不能重新启动播放。
- **笔记**：演示中的草稿与持久笔记分开。明确写入时，锁定笔记与页的稳定 ID，并携带操作 ID。页已切换、结果已失效或来源不匹配时不提交。页面元素、对象登记和撤销应作为一次编辑生效；重试不重复插入。第一版只需要用户与 Agent 共用当前笔记，不引入跨设备多人同步。

先稳定保存、写入与回调，再复用现有动画工具接通这一个演示。首版可用按钮模拟打断，跑通后再接流式语音；语音供应商和完整多人同步先不定。

## 验收

1. 播报中说「停一下」：本机音频和动画立即停止，记录从输入到各自停止的延迟；迟到的旧输出不再播放。
2. 暂停时拖动观测点，或连续给两次修改：只展示最后一次输入所对应的图，面积与最大点间距取自同一场景版本。
3. 提交前切页、取消、延迟渲染或重复点击：不污染另一页，不重复插入。成功时保存并重开仍是同一张图；撤销只撤本次提交。
4. 用 Android 真机跑从打断到落笔的全流程；核对实际屏幕像素、裁切和字幕，不把 JS 回调或模拟测试当画面验收。

### 可重复的几何场景

这是合成教学例子，不需要题目附件。令观测点 A=(0,0)、B=(b,0)，演示目标为 (0,4)，两个测向角的半角均为 arctan(1/4)。用从 A、B 出发的两组向前射线求交，不把屏幕边缘当作区域边界。首版只需在 b=6 和 b=8 间切换。用鞋带公式求面积，枚举交集顶点对求最大点间距。

| b | 面积 | 最大点间距 |
|---:|---:|---:|
| 6 | 10.624 | 7.654 |
| 8 | 11.528 | 7.509 |

第二个点挪远后，面积反而变大，最大点间距却变小。这两个指标因此都值得展示。先暂停，再从 b=6 切到 b=8，然后人为释放一条迟到的 b=6 回调：画板必须保持 b=8，笔记零写入。恢复时只解释 b=8；明确保存时只产生一次编辑。可以复用现有动画滑块、平面相机和静态多边形填充，这个演示本身仍待实现。

语音接通后再测一个不同的场景：学习者说「这个区域的直径是不是……」，短停后补完「一定等于最小覆盖圆的直径？」应用不能抢答半句话。说「我先想一下」后，即使学习者自言自语也不抢话；等到「你继续」再接上原来的步骤。这和「停一下」立即打断播放是两项不同的测试。
